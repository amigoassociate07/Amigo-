# Amigo Associate | Institutional-Grade Financial Study Hub

**Amigo Associate** is a premium, institutional-grade financial education and analysis ecosystem. Designed as a "Command Center" for the modern investor, the platform provides advanced intelligence nodes across multiple asset classes while maintaining a strict academic and study-oriented posture.

---

## 🏛️ Project Mission: Financial Study & Intelligence

Amigo Associate is built on the foundation of rigorous financial study and market visualization. Our mission is to democratize institutional-grade intelligence by providing students, researchers, and market enthusiasts with the tools to study global market dynamics.

### ⚖️ Regulatory Compliance Posture
To ensure 100% alignment with financial regulations, the platform strictly avoids regulated terminology:
- **No "Research"**: Replaced with **"Study"**, **"Analysis"**, or **"Intelligence"**.
- **No "Advisory"**: Replaced with **"Guidance"**, **"Framework"**, or **"Study"**.
- **Education First**: The platform is an educational resource and does not provide investment advice or stock tips.

---

## 🚀 Core Intelligence Modules

### 1. Amigo Pathshala
The core learning engine. A structured pedagogical roadmap covering market basics to advanced institutional execution models.

### 2. Study Portfolio
A real-time analysis terminal that tracks high-conviction market study nodes. 
- **Analysis Nodes**: High-fidelity tracking of equity, forex, and macro-economic vectors.
- **Accuracy Vectors**: Data-driven study of historical trend performance.

### 3. Intelligence Hub (Services)
Deep-dive educational nodes for every asset class:
- **Equity Lab**: Fundamental study and sector intelligence.
- **Forex Study**: Global macro-economic drivers and currency volatility trends.
- **Mutual Funds Study**: Systematic study of SIP, Lumpsum, and ELSS performance frameworks.
- **Capital Protection**: Risk-mitigation models and insurance study.

## 🎨 Design System: The Command Center

The platform utilizes a state-of-the-art **Glassmorphic Command Center** aesthetic:
- **Palette**: Deep Navy (`#0f172a`), Emerald (`#10b981`), and High-Contrast White.
- **Typography**: Strictly upright, high-tracking (letter-spacing) sans-serif fonts for a professional, institutional feel.
- **Animations**: Subtle micro-interactions powered by **Framer Motion** for a living, reactive interface.

---

## 🛠️ Technology Stack

- **Core**: React 18 + Vite
- **Styling**: Tailwind CSS + Custom Vanilla CSS tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Optimized for Vercel

## 🚦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/amigo-associate/platform.git

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Production Build
```bash
npm run build
```
